# JavaScript AI components - hard constraints

`@arcgis/ai-components` (the `arcgis-assistant` component and its agents) is beta. An app designed without the constraints below cannot be deployed. They come from the [FAQ](https://developers.arcgis.com/javascript/latest/agentic-apps/ai-faq/) and the [introduction](https://developers.arcgis.com/javascript/latest/agentic-apps/ai-introduction/).

## Who can use the app

1. Every end user must sign in as a named member of an ArcGIS Online organization. Public and trial accounts do not qualify, and sign-in is required even when the web map is public.
2. API keys cannot enable the components. Do not design an anonymous public app around them.
3. The organization must have AI assistants enabled, must not block beta apps and capabilities, and the user's role needs the AI assistant privilege.
4. ArcGIS Enterprise is not supported. Esri states that support is planned for a later Enterprise release; treat any date as tentative.
5. No charge during the beta; usage-based cost may follow.

## What you cannot change

6. The model behind the Esri agents and the orchestrator is fixed. Agents built with the agent utilities cannot bring their own model; a LangGraph agent can, if you run your own backend.
7. `arcgis-assistant` does nothing on its own: register at least one agent.

## Contract change at 5.1

8. At 5.1 the orchestrator-to-agent contract became structured: an agent receives an execution context (`userRequest`, `assignedTask`, `messages`, `priorSteps`, `sharedState`) and returns a result (`outputMessage`, `status`, `summary`, optional `sharedStatePatch`). Agents written for 5.0 that exchange plain messages may stop working. Read the [release notes](https://developers.arcgis.com/javascript/latest/release-notes/) for the installed version and look up the types with `arcgis_docs_lookup_symbol`.

## Web map embeddings

Needed only for the web-map-based Esri agents, not for custom agents or the Knowledge agent ([setup guide](https://developers.arcgis.com/javascript/latest/agentic-apps/ai-webmap-setup/)):

- Embeddings describe layer titles and field metadata and are stored as a resource on the web map item.
- The item owner or an administrator generates them in the item's settings in ArcGIS Online.
- Agents see feature layers only. Keep layers few, and give layers and fields descriptive names, aliases and descriptions: missing descriptions are generated by a model and cannot be reviewed.

## Building custom agents

Two routes ([guide](https://developers.arcgis.com/javascript/latest/agentic-apps/ai-custom-agents/)): the agent utilities (`LLMAgent`, `FunctionAgent`, `WorkflowAgent`, `FunctionTool`, human-in-the-loop middleware) or a LangGraph agent object. Start from the `ai-components-*` templates in [Esri/jsapi-resources](https://github.com/Esri/jsapi-resources/tree/main/templates).

Do not install `@arcgis/ai-orchestrator` or `@arcgis/ai-agents`: both were folded into `@arcgis/ai-components` (see `brief:legacy/do-not-use`).
